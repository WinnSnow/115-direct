# 整理与刮削

## 目录链路

115接收原件 -> 115分类副本 -> 本地待整理STRM -> 本地成品STRM、NFO、图片。

默认采用115先分类整理的流程，同步来源固定为115分类目录。本地整理与刮削能力保留：自动成品生成复用已确认的匹配；待整理和已完成成品均可通过手动预览纠错、调整季集、重新命名或重新刮削。本地纠错只更新本地成品及关联记录，不自动调整115分类副本，云端目录调整需单独预览确认。

115分类使用电影/电视剧二级分类，不上传刮削信息、不下载视频。分类不明确进入人工处理。接收原件始终保留。客户端播放仍通过原网关返回115 CDN的302，没有新增HLS、转码或视频代理。

本地只有两个目录：`PENDING_PATH`是同步STRM目录（待整理），`STRM_PATH`是刮削成品目录（Jellyfin扫描），不是三个阶段。同步分类目录时，待整理STRM保留云端相对目录层级；成品阶段负责规范命名、季集、版本及NFO和图片。两根目录独立，避免同步覆盖人工整理结果。

项目接收任务复用云端分类时确认的TMDB匹配来生成本地成品，不再匹配一次。仅在115手动摆放二级目录不等于已确认具体作品；扫描这些已有文件时仍需匹配或人工指定TMDB ID。当前定时同步只扫描115分类目录，尚无直接扫描接收目录、仅在本地分类的模式。

“整理策略”页面提供“整理接收目录”按钮，用于扫描115接收目录中带`tmdbid`标记但尚未建立关联的作品。任务沿用当前分类、命名、版本和本地整理方式，进入同一持久任务队列；已完成或部分关联的目录会跳过或标记待确认，避免重复复制。

企业微信的分享消息可解析URL内提取码和消息中的密码。新分享按完整清单接收；再次收到已完成分享时，可按企业微信设置的策略与间隔核对嵌套文件清单，仅补充新增或变更内容。补充任务复用上一任务的已确认TMDB匹配；本地成品仍服从电视剧/电影版本策略。分享中移除文件不触发云端或本地删除。“检查更新 链接”指令立即核对，关闭消息识别开关后不接受新的分享转存。

接收目录清理默认为关闭。启用“完成后按天数清理”并设置保留天数后，服务每小时检查一次；也可以点击“立即清理到期目录”。只有已完成、仍是接收目录直接子目录、存在已验证分类副本的任务才会删除接收目录，分类副本、本地STRM和关联记录保留。定时同步开关不会影响这项清理检查。

```text
/media/115-pending/             # PENDING_PATH，Jellyfin不扫描
  <115原始目录>/原始名称.strm
/media/115-strm/                # STRM_PATH，兼容旧目录为成品目录
  电影/欧美电影|华语电影|日韩电影/片名 (年份)/
    片名 (年份) - 质量 - 1080P [v-唯一标识].strm
    同名.nfo、movie.nfo、poster.jpg、fanart.jpg
  电视剧/国产剧|日韩剧|欧美剧|纪录片|日番|国漫/剧名 (年份)/
    tvshow.nfo、poster.jpg、fanart.jpg
    Season 01/
      剧名 - S01E32 - 第 32 集 - 2160P [v-唯一标识].strm
      同名.nfo、season.nfo、poster.jpg
```

根目录必须独立、存在且可写。首次使用保存设备和目录标识；挂载被替换时暂停修改。不要将整个数据根目录作为待整理目录。

## 命名与人工整理

系统设置提供电影/电视剧模板、季集正则、命名预览和恢复默认。模板只接受已知变量与`{% if 变量 %}` / `{% endif %}`，不执行表达式。

电影默认模板：
```text
{{title}}{% if year %} ({{year}}){% endif %}/{{title}}{% if year %} ({{year}}){% endif %}{% if part %}-{{part}}{% endif %}{% if videoFormat %} - {{videoFormat}}{% endif %}{{fileExt}}
```
电视剧默认模板：
```text
{{title}}{% if year %} ({{year}}){% endif %}/Season {{season}}/{{title}} - {{season_episode}}{% if part %}-{{part}}{% endif %}{% if episode %} - 第 {{episode}} 集{% endif %}{{fileExt}}
```

`season`默认为两位，`season_episode`如`S01E32`，`fileExt`固定`.strm`。模板基础示例为`春花焰 (2024)/Season 01/春花焰 - S01E32 - 第 32 集.strm`；默认共存策略会在实际文件名附加质量和唯一版本标识。

目录管理提供115网盘、本地待整理、本地成品三种视图。115网盘默认浏览根目录，提供接收目录和分类目录快捷入口；根目录、接收目录及分类根外的目录只读浏览，修改操作仍限分类根内。选择本地STRM或作品目录后，使用“整理 / 纠错”，可指定目标子目录、类型、TMDB ID或关键词搜索，修正季集和集号偏移，再预览、确认。多集范围和特别篇必须人工确认；模糊或重叠范围不自动处理。整部作品的批量选择不要包含其他作品。

自动匹配沿用现有评分，候选展示片名、年份、类型评分依据。人工匹配优先。纠错、重新刮削、文件移动均保留播放ID。

复制为默认方式，另支持同文件系统硬链接、软链接及验证成品成功后移除源STRM的移动。软链接指向待整理目录，Jellyfin必须额外以只读方式挂载链接目标到相同容器路径，但扫描位置仍只添加成品二级分类。缺少目标可达性时使用复制或硬链接。

## 版本与删除

版本组由TMDB类型、ID、电影分段或季集范围组成，SHA1辅助去重。分辨率、FPS、HDR/DV、编码和音频分别记录；4K与2160P等同，FPS和杜比不决定清晰度排序。未知质量不自动淘汰已知质量。时间排序使用首次入库时间，而不是最近同步时间。

共存、覆盖、最近入库优先、清晰度优先可选，默认共存。先写入并读取验证新成品，再清理旧版本。清理失败保持执行记录，重试不重复生成新版本。重复及优先级较低的入库保留来源记录并暂停自动重复整理。

| 策略 | 成品及项目元数据 | 待整理 | 115分类文件 |
| --- | --- | --- | --- |
| ① local | 删除 | 删除，无其他有效引用时 | 保留 |
| ② output，默认 | 删除 | 保留，可手动重整 | 保留 |
| ③ chain | 删除 | 删除，无其他有效引用时 | 按记录ID删除 |

明确删除与版本淘汰分别选策略。三种策略均保留数据库关联、暂停旧文件自动重建；①需明确恢复，③需恢复分类源或重新接收后处理。接收原件不参与删除。115使用SDK普通文件删除接口，未调用永久清空回收站；恢复能力须实际接口验证，不承诺云端恢复。

缺失云端源只标记不可用；外部成品缺失可能是删除或移出目录，进入待确认队列，无论扫描多少次都不自动删除云端。未接入可靠Jellyfin明确删除事件，因此Jellyfin删除也按外部缺失处理。

共享对象、软链接目标在有剩余引用时保留并记录原因。元数据使用项目所有权及内容哈希；用户文件和用户改动不覆盖、不删除。NFO及图片原子发布，图片失败有独立执行记录可重试，已删除关联不因重试重新生成元数据。

## 目录操作

新建、重命名、复制、移动和删除均先预览范围、受影响引用，再确认。只能操作配置根内的对象；115通用操作限分类根，不修改接收根。关联STRM必须保持扩展名，单文件的项目NFO一起调整。拆分作品目录、未知软链接、未关联删除、共享文件不明确的批量删除会停止执行。

目录删除仅清理可证明属于项目的文件，未关联/用户文件保留。批量项有独立持久记录可重试。115修改串行、间隔至少一秒，结果不确定时只核对，不重复修改。

## Jellyfin

成品路径中的 `{{title}}` 优先使用 TMDB 大陆中文标题。若中文主标题为空而接口回退到原名，会查询同一 TMDB ID 的中文译名及别名，优先选择大陆名称，再查其他中文地区；原名保留在 NFO 的 `originaltitle` 中。确无中文名称时沿用主标题并记录日志。原有英文成品可从“媒体整理”逐条重新整理为中文命名，播放 ID 与硬链接源关联保留。

本地同步成功后通知 Jellyfin 更新；单文件整理、纠错和刮削完成后再次通知。通知失败会记录原因并显示为失败，可在“媒体整理”逐条重试。关闭定时增量同步不影响手动同步和整理完成后的更新通知。

“媒体整理”按文件显示成功、失败、未识别、待确认、排队中、处理中及版本跳过记录，支持搜索和分页。源路径、成品路径、任务 ID、播放文件 ID、115 文件 ID、整理方式和版本组可在记录中查看。成功记录可按当前设置重新整理；未完成步骤保留执行进度后重试，不重复写入或淘汰版本。手动识别/纠错支持 TMDB 关键词与 ID、季集修正及路径预览，确认后仅提交该文件。已删除或源不可用的记录需先处理关联。

纠错弹窗的关键词搜索按电影/电视剧类型返回候选，候选展示海报、名称、原名、年份与简介。选中候选或输入 TMDB ID 后获取详情，展示中文标题、海报、背景图、日期、类型、评分、时长、地区、语言和简介（以 TMDB 提供的数据为准）。图片经服务器的 TMDB 图片客户端获取，沿用图片代理配置；没有图片或加载失败时显示占位信息，预览不写入本地元数据。

电视剧按需加载所选季的集数列表，可通过季、集下拉框选择，查看季海报及单集标题、剧照、日期、评分、简介。初始季集优先沿用整理记录，未识别文件尝试解析 `SxxExx`；切换季会清空原集号。也可手动输入季集，特别篇和多集文件仍需明确勾选确认，多集文件的集号留空以保留范围。任一整理参数改变均使原路径预览失效，重新预览后才能确认整理。

接口：`GET /api/v1/records/organization?status=failed&q=关键词&limit=25&offset=0`，`POST /api/v1/records/organization/{记录ID}/retry`。记录 ID 支持 URL 编码；变更操作沿用管理员会话和 CSRF 校验。

元数据只读接口：`GET /api/v1/tmdb/details?kind=tv&id=247718`、`GET /api/v1/tmdb/seasons?id=247718&season=1`、`GET /api/v1/tmdb/image?path=/图片文件.jpg`，均需管理员登录。详情和季信息沿用识别缓存，图片使用浏览器私有缓存。

只挂载成品目录且默认只读，分别将`电影/欧美电影`、`电视剧/国漫`等二级分类作为媒体库扫描位置。启用NFO Reader。不要扫描待整理目录，不要将“国漫”等分类误识别为剧名。

确需Jellyfin本地删除时，只将成品挂载改为可写，不开放待整理或其他目录写权限；此类外部缺失仍先待确认。
